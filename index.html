Erdős–Straus 猜想：复现笔记
数学笔记 · 2026 年 11 月 · 不是证明
花了一周，把这个 1948 年提出、至今没解决的猜想从头推了一遍：六条能逐行验算的构造公式，n ≤ 10⁷ 全部给出显式解，剩下的那类数老实写着「没解完」。文里有一节专门记录我两次推翻自己结论的地方。
复现数值实验仍未解决
读笔记（点开看全文）

作者：哈密瓜EMOJI（初一）× Hermes（AI） 时间：2026 年 11 月 性质：复现经典构造 + 自推两条构造族 + 数值实验。本文不声称证明 Erdős–Straus 猜想。

0. 一句话结论

我们把 Erdős–Straus 猜想从零推了一遍，得到六条可逐行验算的构造定理；对 n ≤ 10⁷ 的全部 n 用这些定理 + 参数搜索给出了显式解，全部通过精确有理数验算。但这不是证明——最后一步（对任意 n 都存在这样的参数）与原猜想等价，仍未解决。

1. 问题

Erdős–Straus 猜想（1948，Erdős 与 Straus 独立提出；文献中最早见于 Obláth 同年投稿的论文）：对每个整数 n ≥ 2，方程

(4)/(n)=(1)/(a)+(1)/(b)+(1)/(c)

有正整数解。

已解决到 n ≤ 10¹⁸（Mihnea–Dumitru, 2025），整体仍未证明。

2. 文献对照（重要，先说清哪些是别人的）

本文的定理文献中的对应
定理 A（n+1 被 ≡3 mod 4 的素数整除则可解）Obláth, 1948/1950 已指出
定理 A 推论（“几乎所有 n”）同上，由 Obláth 直接推出
剩余类的压缩Mordell, 1969（mod 840，仅剩 6 类）；Terzi, 1971（198 个坏同余类 mod 120120）
例外集上界Vaughan, 1970：≤ N·exp(−c(log N)^{2/3})；后续改进至 N·exp(−c(ln N)^{3/4})
穷举验证Salez 2014（10¹⁷）、Mihnea–Dumitru 2025（10¹⁸）
解数渐近Elsholtz–Tao, 2013

定理 B、C、D、E、F 是本文在实验过程中独立推出来的，机理与上述“参数解（parametric solutions）”同源；作者未逐条核对文献是否已有完全相同的形式，若有重复，以文献为准。

3. 通用归约

取 k > 0 与 a 满足 4a − n = k，即 a = (n+k)/4（要求 k ≡ −n (mod 4)）。则

\frac4n-\frac1a=(4a-n)/(na)=(k)/(na)

故原方程等价于 1/b + 1/c = k/(na)。记 v = na：

(kb-v)(kc-v)=v^2

引理 1：若 d | v² 且 d + v ≡ 0 (mod k)，则 b = (d+v)/k、c = (v²/d+v)/k 为解。（d = v 时退化为 b = c = 2v/k。）

4. 六条构造定理

定理 A（小因子归约）

若存在 k > 0 满足 k ≡ −n (mod 4) 且 k | n，则

\frac4n=\frac1a+\frac1b+\frac1c,\quad a=(n+k)/(4), b=c=(2na)/(k)

*证明*：同余条件给 a ∈ ℤ⁺；k | n 给 k | na，故 b、c ∈ ℤ⁺。且

\frac1a+(k)/(na)=(n+k)/(na)=(4a)/(na)=\frac4n

∎

推论：n ≡ 3、2、0 (mod 4) 取 k = 1、2、4 即可；n ≡ 1 (mod 4) 且有素因子 p ≡ 3 (mod 4) 取 k = p 即可。故未覆盖的 n 只能满足：n 为奇数且所有素因子 ≡ 1 (mod 4)。

定理 B（n ≡ 5 mod 8）

此时 a = (n+3)/4 为偶数（因 n+3 ≡ 0 mod 8）。

\frac4n=\frac1a+(2)/(an)+(1)/(an),\quad a=(n+3)/(4)

*证明*：1/a + 3/(an) = (n+3)/(an) = 4a/(an) = 4/n，而 3/(an) = 2/(an) + 1/(an)。∎

定理 C（n ≡ 17 mod 24）

此时 a ≡ 2 (mod 3)，令 m = (a+1)/3。

\frac4n=\frac1a+\frac1{mn}+\frac1{amn}

*证明*：1/(mn) + 1/(amn) = (a+1)/(amn) = 3m/(amn) = 3/(an)，再用定理 B 用过的恒等式。∎

定理 D（素数 D ≡ 2 mod 3 族）

设 D 为素数、D ≡ 2 (mod 3)，n ≡ 1 (mod 12)（于是 a ≡ 1 (mod 3)）。若 D | n 或 D | (n+3)，取 m = (a+D)/3：

\frac4n=\frac1a+\frac1{mn}+\frac1{amn/D}

*证明*：a ≡ 1、D ≡ 2 (mod 3) ⟹ a + D ≡ 0 (mod 3)，m 为整数。D 奇素数且 D | (n+3) = 4a ⟹ D | a，故 D | amn，c 为整数。又 1/c = D/(amn)，于是

\frac1{mn}+\frac1c=(a+D)/(amn)=(3m)/(amn)=\frac3{an}

∎

定理 E（n+4 的双 3 mod 4 分解）

若 n + 4 = K·L，且 K ≡ L ≡ 3 (mod 4)，取

a=(n+K)/(4),\quad m=(L+1)/(4),\quad \frac4n=\frac1a+\frac1{mn}+\frac1{amn}

*证明*：KL ≡ 9 ≡ 1 (mod 4) ⟹ n ≡ 1 (mod 4)；n + K = KL − 4 + K = K(L+1) − 4 ⟹ n+K ≡ 0 (mod 4)，a 为整数。L ≡ 3 ⟹ m 为整数。且 a = Km − 1，故

\frac1{mn}+\frac1{amn}=(a+1)/(amn)=(K)/(an)

∎

例（n=73）：77 = 7 × 11，a = 20、m = 3，解答 (20, 219, 4380)：1/20 + 1/219 + 1/4380 = 4/73。

定理 F（E 的参数化推广）

设 n + 4j = k·L，k ≡ L ≡ 3 (mod 4)，m = (L+1)/4，a = (n+k)/4。若 j | a·m·n，则

\frac4n=\frac1a+\frac1{mn}+\frac1{amn/j}

*证明*：同上，a = km − j，故 1/(mn) + j/(amn) = (a+j)/(amn) = km/(amn) = k/(an)。∎

定理 B、C、D 都是 k = 3（a = (n+3)/4）时的不同拆法；定理 E 是 F 在 j = 1 时的特例。F 是本文给出的统一形式。

这与 Landau–Ramanujan 定理（全素因子 ≡1 mod 4 的数计数 ~ C/√(ln x)）一致：剩余集落在这个族中，继承其衰减速度。

7. 两次自查纠错（必须写进来）

  1. 第一版“87% 覆盖”是假数据：k ≡ −n (mod 4) 写成 k ≡ n (mod 4)，导致 a 大面积非整数；另有一次 int64 溢出制造了 5 万条假“验算失败”。
  2. “剩余密度 ≈ 8.4/ln n”是错的：用了累计密度，且筛法漏掉大于 √N 的素因子；SPF 精确重算后正确形式为 0.08/√(ln n)。

这两次都是程序自查发现的，不是别人指出来的。

8. 结论

  1. 猜想没有被证明。 定理 F 要求存在 (j, k)，而“对任意 n 都存在这样的 (j,k)”与原猜想一样难；j 随 n 增大（10⁷ 内最大到 128,567），说明这条路线只能逼近。
  2. 本文的实质产出：六条可验算的构造定理、统一参数化形式（定理 F）、10⁷ 内完整验证、剩余集刻画与密度规律。
  3. 与文献相比：定理 A（及“几乎所有 n”）属于 Obláth 1948 的已有结果；Mordell、Terzi、Vaughan 走得更远；我们的数值范围（10⁷）远小于 Salez（10¹⁷）。
  4. 一句话：能复现、能验证、能纠错；不能无中生有。
